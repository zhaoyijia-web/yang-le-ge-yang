# 羊了个羊 · 草原消消乐

一个单文件实现的「羊了个羊」风格草原三消小游戏，使用原生 HTML / CSS / JavaScript，无外部依赖。

**在线试玩：** https://zhaoyijia-web.github.io/yang-le-ge-yang/

## 玩法

点击没有被上层压住的卡片，把三张相同图案凑进下方卡槽即可消除。卡槽只有 7 格，塞满则本局失败；清空全部卡片即可通关。

## 内容

- 16 个关卡，分为青草、月夜、云端、终章四章
- 14 种手绘 SVG 图案
- 撤销、洗牌、移出三种道具
- 关卡逐步解锁，通关进度保存在浏览器本地
- 单文件 `index.html`，可直接部署到任意静态托管

## 本地运行

```bash
cd 羊了个羊
python3 -m http.server 8000
```

打开 http://localhost:8000/ 。

## 说明

所有进度均保存在当前浏览器本地，无后端、无账号系统，不同设备的进度相互独立。
